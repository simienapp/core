# simien

The Simien runtime executable: a multi-core JavaScript runtime for WinterTC-style apps, with Simien's backend built in.

This version only reserves the name. The runtime is built at [simienapp/runtime](https://github.com/simienapp/runtime) on the engine crates from [simienapp/core](https://github.com/simienapp/core) (`simien_core`, `simien_web`, `simien_fetch`, …).
